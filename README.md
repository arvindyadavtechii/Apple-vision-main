# 🍎 Apple Vision Pro – Spatial Computing Website

A modern, immersive Apple Vision Pro–inspired landing page showcasing the future of spatial computing. This project recreates Apple’s premium design language with smooth animations, elegant layouts, and visually rich sections — optimized for performance and responsiveness.

Live Demo: https://apple-vision-main-two.vercel.app/

---

## 🚀 Features

- Premium Apple-style UI/UX
- Spatial computing concept presentation
- Interactive “Watch Film” and “Watch Event” sections
- Apps in Space showcase
- Detailed design and technology sections
- Fully responsive design (mobile, tablet, desktop)
- Fast loading and optimized performance
- Deployed on Vercel

---

## 🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript  
Styling: Modern CSS (Flexbox, Grid, Animations)  
Deployment: Vercel  
Design Inspiration: Apple Vision Pro (apple.com)
